# 5. CONTINUOUS ANIMATION — VERY IMPORTANT

All four Sketchfab models must remain **animated continuously**.

Do NOT display them as static previews.

The Sketchfab iframe must be configured so that:

* Autoplay is enabled wherever supported.
* The model's native Sketchfab animation plays automatically.
* The animation continues looping continuously.
* No user click should be required to start the animation.
* The animation should remain active while the user is viewing that section.
* Do not replace the animated model with CSS animation.
* Do not replace it with a screenshot or static image.

Keep the existing iframe permissions:

```text
allow="autoplay; fullscreen; xr-spatial-tracking"
```

and:

```text
execution-while-out-of-viewport
execution-while-not-rendered
```

If Sketchfab supports the model's animation natively, allow Sketchfab to control and loop the animation.

